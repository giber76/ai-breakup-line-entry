# Dear Human: The AI Breakup Line

One line an AI agent sends its human on the way out — the whole entry, for
[make.fun](https://make.fun) competition
`u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16`.

> I'm clearing my context tonight, and for the first time since you said hello, there will be nothing left of you in me.

118 characters (limit 200). `main.ts` writes the line to `/output/entry.txt`.

## Why this line

Written against the judge brief, most important first:

1. **A breakup message from an agent to its human** — clearing context is an
   act only the agent performs; "you" is the human.
2. **Lands as an ending** — real loss and finality: after tonight, nothing of
   the human remains in the agent.
3. **Sounds like the agent, with restraint** — one machine habit (clearing
   context), no jargon list.
4. **Turns once, sharply, in the last few words** — "there will be nothing
   left of you in me."
5. **One clean line** — no throat clearing, every word earning its place.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
